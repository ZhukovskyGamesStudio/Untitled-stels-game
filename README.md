# Айтишники: вылазка — прототип кор-лупа

Кооперативный стелс-рогалик. Дизайн-документ: https://claude.ai/artifact/GdaGu25vZ1ezVUmZ8KWFap

Unity 6000.6.0f1, URP, Netcode for GameObjects 2.13, Steamworks.NET (AppID 480 / Spacewar для разработки).

## Как запустить

- Сцена: `Assets/_Game/Scenes/Game.unity`.
- **Через Steam:** «Создать игру через Steam», затем Esc → «Пригласить друзей». Друг заходит по приглашению или через «Присоединиться к игре» в Steam.
- **На одном ПК / в локалке:** «Создать локальную игру» в одном окне, «Подключиться по IP» в другом (UDP, порт 7777). В редакторе второго игрока удобно запускать через Window → Multiplayer → Multiplayer Play Mode.
- Ассеты (материалы, префабы уровня, роботов, интерфейса, сцену) собирает код: меню **Stealth → Build Missing Assets** — только недостающее (ручные правки префабов сохраняются), **Stealth → Rebuild All Assets** — всё заново. Windows-билд: **Stealth → Build Windows Player** (в `Builds/Windows`).
- Модели-заглушки генерируются в Blender: `generate_models.py` (офис, игрок, предметы) и `robots.py` (роботы и датчики):
  `blender.exe -b --factory-startup --python Tools/Blender/robots.py -- Assets/_Game/Art/Models` (раскладываются по подпапкам).
- Звуки и музыка синтезируются скриптом `python Tools/Audio/generate_sounds.py` (numpy + scipy) в `Assets/_Game/Art/Audio`;
  какой клип где звучит — `Data/SoundBank.asset`, громкости и дальности — `Data/Config/Audio.asset`.
  Голос роботов («Обнаружен нарушитель», «Веду преследование», «Нарушитель потерян») — `python Tools/Audio/generate_voices.py`
  (русский голос синтеза речи Windows + обработка «под робота»).
- Как устроен код и как с ним работать — [CLAUDE.md](CLAUDE.md).

## Как настраивать баланс

Все крутилки — ScriptableObject-конфиги, их можно править в инспекторе прямо во время игры в редакторе:
`Assets/_Game/Data/Config/` — **Player** (движение, выносливость, шум, газ, взлом), **Run** (квота, тревоги, охотник),
**Level** (размер здания, комнаты, сколько и какой охраны с какого дома, лут), **Items** (ценность и частота цветов),
**Audio** (громкость групп звуков, дальность слышимости, шаги, смена музыки);
у каждого робота, устройства и лазера свой конфиг рядом с префабом — `Prefabs/Robots/RobotTurretConfig.asset`, `Prefabs/Sensors/SecurityCameraConfig.asset` и т. д.
(глаза, слух, скорости, дальность, время прицеливания, анимация…). Префабы и конфиги — разные файлы, их можно менять независимо.
Подробнее — раздел «Настройки» в [CLAUDE.md](CLAUDE.md).

## Игра с другом через Steam

1. Оба запускают один и тот же билд (Steam запущен, вы друзья).
2. Один нажимает «Создать игру через Steam».
3. У второго справа в главном меню, в «Друзья в игре», появится строка с его ником — «Войти». Список обновляется сам раз в 5 секунд.
   Ещё варианты: Esc → «Пригласить друзей» у хоста, или «Присоединиться к игре» у друга в списке друзей Steam.
4. Если билды разные, в строке будет «другая версия игры» — обновитесь до одного.

**Команда** — айтишники четырёх отделов (по месту в лобби): бэкенд-разработчик в худи и наушниках, тестировщик с бейджем
и клипбордом, сисадмин в жилете с мотком кабеля, дизайнер в берете и шарфе. Цвет игрока — рюкзак и повязка на рукаве.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD | ходьба (быстрый разгон, чёткая остановка) |
| Shift | бег — громко, тратит выносливость (~6 с) |
| Пробел | прыжок (перепрыгнуть нажимную плиту, луч лидара, подвижный лазер внизу) |
| Ctrl (держать) / C (переключить) | присед — тихо, пролезть в вентиляцию и под лазером |
| ЛКМ на предмете | зажми и тащи в рюкзак (камера стоит, пока кнопка зажата); клик — в первое свободное место |
| Tab (держать) | «руки»: курсор, тащи предметы между рюкзаком, полом и складом у люка; R — повернуть, T — отзеркалить |
| E (держать) | поднять союзника (без сознания) · взломать устройство или робота сзади/сбоку (1,75 с, на 30 с; отошёл — прогресс сохраняется) |
| Пробел (лёжа) | встать, если после удара осталось 1 ХП |
| F у люка | спрятаться в люк / вылезти обратно (когда в люке вся команда — уходите в канализацию) |
| E у запертой двери (держать) | взломать замок (красная лампа над дверью; роботы ходят через такие двери свободно) |
| E у терминала | терминал охраны: смотреть камеры дома · терминал взлома: держи E — взломать робота на экране (3 заряда на дом); A/D или ЛКМ/ПКМ — другой, Пробел — встать |
| E у сейфа | вскрыть сейф: крути диск мышью, слушай щелчки, ЛКМ/E — попробовать цифру (ошибка громко лязгает) |
| СКМ (колесо) | пинг «сюда»: команда видит метку сквозь стены и на карте |
| Q | пометить робота в прицеле: вся команда 12 с видит его сквозь стены (красный силуэт) и на карте |
| M | большая карта этажа (колесо мыши — другой этаж); мини-карта всегда в правом нижнем углу |
| Esc | пауза и **всё управление** с переназначением клавиш; настройки (чувствительность, FOV, инверсия, покачивание, режим приседа, громкость, музыка) |
| G | у люка — сложить всё из рюкзака на склад команды |
| F8 | следующий визуальный стиль — у всей команды сразу (прототипы арт-направления) |
| K или Esc → «Я застрял» | вытащить на ближайшее свободное место (раз в 8 с) |
| ЛКМ / ПКМ без сознания | смотреть глазами другого союзника (пинг и метка работают из его глаз) |

Любую клавишу можно переназначить: Esc → кликни по клавише в списке → нажми новую (или кнопку мыши). Сохраняется сразу,
подсказки в игре называют уже новые клавиши. Из главного меню — кнопка «Управление».

**Карта.** Сначала карта пустая. Где кто-то из команды прошёл и посмотрел — туман рассеивается: видны очертания комнат,
двери, лестницы и мебель. Сквозь стены карта не открывается, через дверной проём — да. Карта общая: один разведывает,
остальные носят добычу и видят разведанное.

Посмотри на робота полсекунды — под прицелом появится, кто это и чем он тебя замечает. Чувства видно и по самому роботу:
глаз-камера — видит, микрофоны — слышит, щупы в пол — чувствует шаги, нос — идёт по запаху.

**Удар.** Каждый удар робота сбивает с ног. Лежачего роботы не трогают: робот говорит «Нарушитель устранён» и уходит —
полежи, пока он не скроется, и вставай (Пробел), если осталось 1 ХП. Без ХП поднять может только союзник. Новый вид робота
обязательно встречается в доме, где он впервые появляется. Камера, замечая тебя, пикает всё чаще.

**Как роботы замечают.** Ничего не срабатывает мгновенно: над роботом, который тебя замечает, заполняется шкала подозрения.
Чем хуже ему тебя видно, тем медленнее: дальше, за мебелью видна только часть тела (15% тела с 5 м — почти никогда),
на краю обзора, присев, стоя на месте, и чем меньше на тебе света: считается свет всех ламп вокруг, луны и эмбиента
с учётом преград (стоять в пятне от настольной лампы или в лунном свете у окна опасно). Над инвентарём — индикатор
«в тени / полумрак / заметно / на свету». За спиной робот чувствует тебя очень слабо — можно подкрасться и взломать.
Шаги слышно тем тише, чем дальше и чем больше преград: стена глушит сильнее закрытой двери, дверь — сильнее мебели,
перекрытие между этажами — почти всё. Тихий шаг — робот оборачивается, несколько — идёт проверить. Шкала полная —
робот останавливается и говорит «Обнаружен нарушитель»: полторы секунды, чтобы спрятаться. Потом «Веду преследование» —
он бежит туда, где видел тебя в последний раз. Как быстро что замечает — `Data/Config/Perception.asset`.

**Люк и склад команды.** Над люком висит доска: сетка «Склад команды» и зона «Продать на квоту». С Tab перетащи предмет из
рюкзака (или с пола) в «Продать» — он сразу идёт в квоту, или на склад — он остаётся у команды на весь забег и его можно
продать позже, например на квоту следующего дома. Склад общий: любой игрок у люка может забрать вещь обратно в рюкзак.

**Забег начинается в канализации.** Кирпичный туннель от лестницы, тележка команды (всё, что лежит на складе, видно в её кузове),
зал с колодцем и туннели к следующим домам — над каждым панель: что за дом, сколько этажей, охраны, камер, тёмных комнат и запертых
дверей. Путь выбирают ногами: каждый заходит в туннель, куда хочет; когда в туннелях все — большинство решает (ничья — жребий),
отсчёт 3 с, и команда в доме. Тупиковые туннели закрыты решёткой.

**Уйти из дома можно в любой момент.** F у люка — спрятаться в люк: крышка открывается, ты сидишь внутри и выглядываешь у самого
пола (смотреть можно, ходить нет), роботы тебя не видят, сверху написано, кого ждём. Вылезти — снова F. Когда в люке все, кто может ходить (лежащие без сознания остаются, и каждый поднимает квоту
следующего дома), идёт отсчёт 5 секунд — и команда снова в **канализации**: у тележки можно допродать добычу из рюкзаков и склада.
Маршрут как в Slay the Spire: из каждого дома 1–3 пути дальше. Чтобы пройти дальше, квота дома должна быть выплачена: если её
нет, канализацию затапливает и забег кончается. Пока все дома — офисы.

**Запертые двери и сейфы.** С дома 2 часть раздвижных дверей заперта (красная лампа): игрок взламывает замок за 3 с (держать E),
роботы проходят свободно — можно проскочить следом. Сейф вскрывается мини-игрой: диск с числами 0–39, чем ближе к нужному
числу, тем громче щелчки; три цифры — и из сейфа выпадает ценная добыча. Неверная попытка громко лязгает — роботы с
микрофонами придут проверить.

## Здание

Генератор (`Scripts/Level`) строит офис из комнат на сетке, **2–4 этажа**. Дом растёт с каждым домом забега: 3×3 комнаты на этаже
в первом, +2,5 комнаты на этаж с каждым следующим, до 6×6. Чем больше команда, тем больше дом (площадь ×1,25 на двоих, ×1,45 на троих,
×1,6 на четверых) и квота (доля ×1,1 / ×1,18 / ×1,25 — плюс в большом доме больше добычи), но не ×N. Дом строится под тех, кто в игре
на его старте; друг, зашедший посреди дома, поднимает только квоту. Настройки — `Data/Config/Level` (`AreaByPlayers`) и `Data/Config/Run` (`QuotaByPlayers`).
Лестницы — в углах комнат, с проёмами и перилами.
Комнаты: опенспейс, кабинет, переговорка, кухня, серверная, склад (лут на полках), санузел, зона отдыха, лобби с ресепшеном.
Расстановка — по планировкам реальных офисов: кластеры столов с перегородками, кухонька вдоль стены, ряды стоек, стеллажи, лаунж.
**Свет:** по две потолочные панели на комнату с мягкими тенями, настольные лампы и торшеры, зелёные таблички «Выход» над дверями,
подсветка автоматов, луна светит в окна (полосы от жалюзи), bloom. В тёмных комнатах лампы выключены — только таблички, забытые лампы
и луна; куда свет не попадает — там полная темнота (эмбиента нет, стены и перекрытия отбрасывают тени). Мерцающие лампы, красный свет при тревоге, раздвижные двери (закрытые перекрывают обзор),
**вентиляционные лазы** (только присев) и **узкие щели** в стенах (протиснуться в рост) — роботы не пролезают ни туда, ни туда; **терминалы** на столах (камеры, взлом издалека), окна с рамами и жалюзи. Снаружи — густой газ: в паре метров от стены дом уже не видно. Лут ценнее на верхних этажах и в темноте.

## Роботы и датчики

| Кто | Чем замечает | Как обойти | Этажи |
| --- | --- | --- | --- |
| Охранник | глаза (глухой) | вне конуса, за мебелью, присед, темнота | ходит по лестницам |
| Слухач | только микрофоны | присед, не бегать | колёса — свой этаж |
| Дрон | камера сверху, поднимает тревогу | укрытия над головой | летает везде |
| Паук | глаза со стены и с потолка, прыгает | не стоять под ним, увернуться | своя комната |
| Пылесос (потолок) | лазерный веер от потолка до пола | не попасть под веер: обойти, пока отвернулся, или взломать | своя комната |
| Турель | глаза, целится лазером и стреляет | уйти из прицела за секунду | стоит |
| Сейсмик | бьёт в пол, по полу бежит волна (видно кольцо, сквозь стены) | замереть, пока волна проходит | гусеницы — свой этаж |
| Подметальщик | лидар у самого пола (красная линия) — слепой и глухой | встать на стул, стол, теннисный стол; перепрыгнуть линию | колёса — свой этаж |
| Ищейка | запах — идёт по следу | не оставлять следов рядом | ходит по лестницам |
| Сортировщик | видит только лут своего цвета | не нести этот цвет | ходит по лестницам |
| Рабочий | глаза — не дерётся, доносит; часто везёт лут на подносе | взломать — уронит лут | колёса — свой этаж |
| Охотник | всё сразу | не поднимать тревог; убегать (бежит чуть медленнее бега игрока) | приходит после 3 тревог или по таймеру — отсчёт и тревоги до него видны под квотой, за минуту — предупреждение |
| Лидар | луч у пола | перепрыгнуть | стоит |
| Датчик движения | любое движение (быстрее — быстрее заметит) | замереть | на стене |
| Нажимная плита | вес | перепрыгнуть или взломать (обойти нельзя: лежит прямо в дверном проёме) | стальная плита в проёме со светящейся рамкой |
| Камера, лазерные барьеры | обзор / лучи (низкий, мигающий, подвижный) | тайминг, присед, прыжок | — |

Роботы переговариваются по радио (вызывают соседей проверить место), над ними видно «?» и «!».
Первые 8 секунд уровня датчики выключены.

## Точки стыковки для коллеги

- **Войс-чат:** вызывать `NoiseSystem.EmitServer(позиция, радиус, clientId)` на сервере, радиус — от громкости микрофона. Роботы с микрофонами услышат.
- **Предметы:** сейчас `ItemCatalog` (форма + цвет), расстановка — `LootPlanner`. Для настоящих предметов — заменить каталог и `WorldItem`; инвентарь работает с формой в клетках.
- **Мета-прогрессия:** итог забега — `GameManager.RunTotal`, конец забега — `GameManager.Phase == Failed`.
- **Новый робот:** чек-лист в `.claude/skills/stealth-code/SKILL.md` (значение в `RobotKind`, строка в `RobotRoster`, префаб в `AssetBuilder.Actors.cs`, описание в `RobotInfo`).

## Тесты и автопилот

- `Tools/dev.sh tests` — EditMode-тесты (≈340: движение, здоровье и газ, инвентарь, генерация и навмеш этажей, сборка уровня из префабов, «мозг» роботов, датчики, подсказки HUD, целостность префабов, граница с сетевым слоем, мебель не клипает в стены, склад команды, звук).
- `Tools/dev.sh assets` (`FORCE=1` — перезаписать всё) / `Tools/dev.sh player` — собрать ассеты / Windows-билд в batchmode.
- `Tools/dev.sh run <сценарий> [клиенты]` — запустить билд с автопилотом, он пишет `[AUTOTEST]` в лог и сохраняет скриншоты в `Builds/shots/<сценарий>`.
  Переменные: `SEED`, `LEVEL`, `PEACEFUL=1`, `HOSTILE=1`, `KINDS=Guard,Drone`, `RESW/RESH`.
  Сценарии: `full`, `coop`, `move`, `ui`, `menu`, `floors`, `rooms`, `vent`, `perf`, `gallery` (все роботы, с `HOSTILE=1` — проверка реакции), `hunter`, `lasers`, `radio`, `hack`.
