# Айтишники: вылазка — прототип кор-лупа

Кооперативный стелс-рогалик. Дизайн-документ: https://claude.ai/artifact/GdaGu25vZ1ezVUmZ8KWFap

Unity 6000.6.0f1, URP, Netcode for GameObjects 2.13, Steamworks.NET (AppID 480 / Spacewar для разработки).

## Как запустить

- Сцена: `Assets/_Game/Scenes/Game.unity`.
- **Через Steam:** «Создать игру через Steam», затем Esc → «Пригласить друзей». Друг заходит по приглашению или через «Присоединиться к игре» в Steam.
- **На одном ПК / в локалке:** «Создать локальную игру» в одном окне, «Подключиться по IP» в другом (UDP, порт 7777). В редакторе второго игрока удобно запускать через Window → Multiplayer → Multiplayer Play Mode.
- Пересобрать всё сгенерированное (материалы, префабы, сцену): меню **Stealth → Build Prototype Assets**. Windows-билд: **Stealth → Build Windows Player** (в `Builds/Windows`).
- Модели-заглушки генерируются в Blender: `blender.exe -b --factory-startup --python Tools/Blender/generate_models.py -- Assets/_Game/Models`.

## Управление

WASD — ходьба, Shift — бег (громко), Ctrl/C — присесть (тихо, можно пролезть под лазером).
**Tab (держать)** — камера замирает, появляется курсор: перетащи предмет из мира в сетку, чтобы подобрать; из сетки в мир — выбросить; на люк — сдать на квоту. R — повернуть предмет.
E (держать) — поднять упавшего союзника. F у люка — следующий дом. Esc — меню. H — скрыть подсказку.

## Что есть

| Система | Где | Коротко |
| --- | --- | --- |
| Steam-сеть | `Scripts/Net` | Лобби для друзей, транспорт NGO поверх Steam Networking Sockets, запасной UDP-транспорт |
| Генерация уровня | `Scripts/Level/LevelGenerator.cs` | Офис из комнат на сетке: остовное дерево + петли, типы комнат с мебелью, двери на улицу. Детерминирован по сиду на всех клиентах |
| Предметы | `Scripts/Items` | Тетрис-детали, очки = клетки × множитель цвета × 5 |
| Персонаж | `Scripts/Player` | FPS-контроллер, 2 ХП, падение и подъём, шум шагов, весёлый газ снаружи (25 с) |
| Роботы | `Scripts/Enemies/RobotController.cs` | Охранник (зрение + слабый слух) и «слухач» на колёсах (слепой, слышит издалека) |
| Камеры, лазеры | `Scripts/Enemies` | Камера качается и поднимает тревогу; лазер — низкий луч (пролезть присев) или мигающая решётка |
| Квота | `Scripts/Game/GameManager.cs` | ~35% стоимости предметов дома, растёт с уровнем, +15% за каждого упавшего |

## Точки стыковки для коллеги

- **Войс-чат:** вызывать `NoiseSystem.EmitServer(позиция, радиус, clientId)` на сервере, радиус — от громкости микрофона. Роботы с микрофонами услышат.
- **Предметы:** сейчас `ItemCatalog` (форма + цвет). Для настоящих предметов — заменить каталог и `WorldItem`; инвентарь работает с формой в клетках.
- **Мета-прогрессия:** итог забега — `GameManager.RunTotal`, конец забега — `GameManager.Phase == Failed`.

## Тест-автопилот

```
StealthPrototype.exe -nosteam -host-local -autotest host -autotest-linger -shotdir <папка>
StealthPrototype.exe -nosteam -join-local 127.0.0.1 -autotest client -shotdir <папка>
```
Оба окна сами проходят сценарий (подбор, сдача, робот, камера, лазер, газ), пишут `[AUTOTEST]` в лог и сохраняют скриншоты.
