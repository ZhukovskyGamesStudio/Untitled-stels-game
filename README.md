# Айтишники: вылазка — прототип кор-лупа

Кооперативный стелс-рогалик. Дизайн-документ: https://claude.ai/artifact/GdaGu25vZ1ezVUmZ8KWFap

Unity 6000.6.0f1, URP, Netcode for GameObjects 2.13, Steamworks.NET (AppID 480 / Spacewar для разработки).

## Как запустить

- Сцена: `Assets/_Game/Scenes/Game.unity`.
- **Через Steam:** «Создать игру через Steam», затем Esc → «Пригласить друзей». Друг заходит по приглашению или через «Присоединиться к игре» в Steam.
- **На одном ПК / в локалке:** «Создать локальную игру» в одном окне, «Подключиться по IP» в другом (UDP, порт 7777). В редакторе второго игрока удобно запускать через Window → Multiplayer → Multiplayer Play Mode.
- Ассеты (материалы, префабы уровня, роботов, интерфейса, сцену) собирает код: меню **Stealth → Build Missing Assets** — только недостающее (ручные правки префабов сохраняются), **Stealth → Rebuild All Assets** — всё заново. Windows-билд: **Stealth → Build Windows Player** (в `Builds/Windows`).
- Модели-заглушки генерируются в Blender: `generate_models.py` (офис, игрок, предметы) и `robots.py` (роботы и датчики):
  `blender.exe -b --factory-startup --python Tools/Blender/robots.py -- Assets/_Game/Art/Models` (раскладываются по подпапкам).
- Звуки и музыка синтезируются скриптом `python Tools/Audio/generate_sounds.py` (numpy + scipy) в `Assets/_Game/Art/Audio`;
  какой клип где звучит — `Data/SoundBank.asset`, громкости и дальности — `Data/Config/Audio.asset`.
- Как устроен код и как с ним работать — [CLAUDE.md](CLAUDE.md).

## Как настраивать баланс

Все крутилки — ScriptableObject-конфиги, их можно править в инспекторе прямо во время игры в редакторе:
`Assets/_Game/Data/Config/` — **Player** (движение, выносливость, шум, газ, взлом), **Run** (квота, тревоги, охотник),
**Level** (размер здания, комнаты, сколько и какой охраны с какого дома, лут), **Items** (ценность и частота цветов),
**Audio** (громкость групп звуков, дальность слышимости, шаги, смена музыки);
у каждого робота, устройства и лазера свой конфиг рядом с префабом — `Prefabs/Robots/RobotTurretConfig.asset`, `Prefabs/Sensors/SecurityCameraConfig.asset` и т. д.
(глаза, слух, скорости, дальность, время прицеливания, анимация…). Префабы и конфиги — разные файлы, их можно менять независимо.
Подробнее — раздел «Настройки» в [CLAUDE.md](CLAUDE.md).

## Игра с другом через Steam

1. Оба запускают один и тот же билд (Steam запущен, вы друзья).
2. Один нажимает «Создать игру через Steam».
3. У второго справа в главном меню, в «Друзья в игре», появится строка с его ником — «Войти». Список обновляется сам раз в 5 секунд.
   Ещё варианты: Esc → «Пригласить друзей» у хоста, или «Присоединиться к игре» у друга в списке друзей Steam.
4. Если билды разные, в строке будет «другая версия игры» — обновитесь до одного.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD | ходьба (быстрый разгон, чёткая остановка) |
| Shift | бег — громко, тратит выносливость (~6 с) |
| Пробел | прыжок (перепрыгнуть нажимную плиту, луч лидара, подвижный лазер внизу) |
| Ctrl (держать) / C (переключить) | присед — тихо, пролезть в вентиляцию и под лазером |
| ЛКМ на предмете | зажми и тащи в рюкзак (камера стоит, пока кнопка зажата); клик — в первое свободное место |
| Tab (держать) | «руки»: курсор, тащи предметы между рюкзаком, полом и складом у люка; R — повернуть |
| E (держать) | поднять союзника · взломать устройство или робота со спины (на 20 с) |
| F у люка | следующий дом |
| Esc | меню, настройки (чувствительность, FOV, инверсия, покачивание, режим приседа, громкость, музыка) |
| H | справка |

Посмотри на робота полсекунды — под прицелом появится, кто это и чем он тебя замечает. Чувства видно и по самому роботу:
глаз-камера — видит, микрофоны — слышит, щупы в пол — чувствует шаги, нос — идёт по запаху.

**Люк и склад команды.** Над люком висит доска: сетка «Склад команды» и зона «Продать на квоту». С Tab перетащи предмет из
рюкзака (или с пола) в «Продать» — он сразу идёт в квоту, или на склад — он остаётся у команды на весь забег и его можно
продать позже, например на квоту следующего дома. Склад общий: любой игрок у люка может забрать вещь обратно в рюкзак.

## Здание

Генератор (`Scripts/Level`) строит офис из комнат на сетке, **2–4 этажа**, лестницы в углах комнат с проёмами и перилами.
Комнаты: опенспейс, кабинет, переговорка, кухня, серверная, склад (лут на полках), санузел, зона отдыха, лобби с ресепшеном.
Расстановка — по планировкам реальных офисов: кластеры столов с перегородками, кухонька вдоль стены, ряды стоек, стеллажи, лаунж.
Тёмные комнаты (роботы видят хуже), мерцающие лампы, красный свет при тревоге, раздвижные двери (закрытые перекрывают обзор),
**вентиляционные лазы** (только присев; роботы не пролезают), окна с рамами и жалюзи, фонари на улице. Лут ценнее на верхних этажах и в темноте.

| Сортировщик | видит только лут своего цвета | не нести этот цвет | ходит по лестницам |
| Рабочий | глаза — не дерётся, доносит | — | колёса — свой этаж |
| Охотник | всё сразу, быстрый | не поднимать тревог | приходит после 3 тревог |
| Лидар | луч у пола | перепрыгнуть | стоит |
| Датчик движения | быстрое движение | красться присев | на стене |
| Нажимная плита | вес | перепрыгнуть или обойти | в полу |

Роботы переговариваются по радио (вызывают соседей проверить место), над ними видно «?» и «!».
Первые 8 секунд уровня датчики выключены.

## Точки стыковки для коллеги

- **Войс-чат:** вызывать `NoiseSystem.EmitServer(позиция, радиус, clientId)` на сервере, радиус — от громкости микрофона. Роботы с микрофонами услышат.
- **Предметы:** сейчас `ItemCatalog` (форма + цвет), расстановка — `LootPlanner`. Для настоящих предметов — заменить каталог и `WorldItem`; инвентарь работает с формой в клетках.
- **Мета-прогрессия:** итог забега — `GameManager.RunTotal`, конец забега — `GameManager.Phase == Failed`.
- **Новый робот:** чек-лист в `.claude/skills/stealth-code/SKILL.md` (значение в `RobotKind`, строка в `RobotRoster`, префаб в `AssetBuilder.Actors.cs`, описание в `RobotInfo`).

## Тесты и автопилот

- `Tools/dev.sh tests` — EditMode-тесты (≈340: движение, здоровье и газ, инвентарь, генерация и навмеш этажей, сборка уровня из префабов, «мозг» роботов, датчики, подсказки HUD, целостность префабов, граница с сетевым слоем, мебель не клипает в стены, склад команды, звук).
- `Tools/dev.sh assets` (`FORCE=1` — перезаписать всё) / `Tools/dev.sh player` — собрать ассеты / Windows-билд в batchmode.
- `Tools/dev.sh run <сценарий> [клиенты]` — запустить билд с автопилотом, он пишет `[AUTOTEST]` в лог и сохраняет скриншоты в `Builds/shots/<сценарий>`.
  Переменные: `SEED`, `LEVEL`, `PEACEFUL=1`, `HOSTILE=1`, `KINDS=Guard,Drone`, `RESW/RESH`.
  Сценарии: `full`, `coop`, `move`, `ui`, `menu`, `floors`, `rooms`, `vent`, `perf`, `gallery` (все роботы, с `HOSTILE=1` — проверка реакции), `hunter`, `lasers`, `radio`, `hack`.
